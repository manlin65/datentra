SONJA-SEITE – INSTALLATION

Lade den kompletten Inhalt dieses Ordners nach:
/Sonja/

Öffentliche URL:
https://datentra.mlinner-software.de/Sonja/

Status-URL:
https://datentra.mlinner-software.de/Sonja/status.php

Eigenen Browser vom Zähler ausschließen:
https://datentra.mlinner-software.de/Sonja/?admin=1

Wichtig:
- PHP muss auf dem Webspace aktiv sein.
- counter.json muss für PHP beschreibbar sein.
- Dein eigener Browser wird nach ?admin=1 per Cookie ausgeschlossen.
- Andere Browser/Inkognito/andere Geräte werden weiterhin gezählt.
